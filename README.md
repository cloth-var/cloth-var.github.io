Project page for the paper **Paper Title** (under review).

## Editing

- `index.html` holds all content (title, abstract, links, results, BibTeX). Search for `TODO` comments.
- `static/` holds figures and media. Replace `teaser.svg` and `method.svg` with the real figures.
- `.nojekyll` makes GitHub Pages serve the files as-is (no Jekyll build step).

GitHub Pages deploys automatically from the `main` branch. Changes usually appear within a minute or two.
