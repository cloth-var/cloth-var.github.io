# Project page

Project page for the paper **Same Action, Different Outcome: Variability in Dynamic Cloth Manipulation** (under review).

Live site: https://cloth-var.github.io

- `index.html` is generated; `static/` holds the figures, the video and the vendored stylesheets.
- `.nojekyll` makes GitHub Pages serve the files as-is. Pages deploys from `main`.
- The page template is borrowed from the [Nerfies](https://nerfies.github.io) project page (CC BY-SA 4.0), with its analytics and external resources removed.
